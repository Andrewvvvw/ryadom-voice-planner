# Проверка результата

Все проверки выполняются на настоящем SQLite через тот же Repository, который использует Worker. Сеть и платные ключи не нужны.

```bash
npm ci
npm test
node --check public/app.js
python3 scripts/convert-data.py
git diff --exit-code -- data/events.json
```

41 сценарий в четырёх файлах. Тесты дат используют фиксированное время `2026-10-31T09:00Z`, а не текущую дату машины.

| Требование | Проверка |
| --- | --- |
| Создание задачи/напоминания | Семь примеров русских фраз: даты, время, содержание, без даты |
| Создание встречи | Время указано / время уточняется вторым сообщением |
| Периоды | Сегодня, завтра, послезавтра, следующая неделя, год, явный диапазон; исключение end |
| Старые события | Исходные 1 000 записей, словоформы, контракт/договор, опечатка, отсутствие совпадений |
| Хранение | Реальная SQLite на диске: закрытие, повторное открытие, продолжение уточнения |
| Дополнительные действия | Контекст «перенеси её», завершение, удаление только после подтверждения |
| Неоднозначность | Несколько кандидатов не изменяются автоматически |
| Конфликты | Наложение, переход полуночи, корректировка времени, подтверждение |
| Повторы и конкуренция | Один requestId — одна запись, изменение тела — 409, одна ревизия — один победитель |
| Изоляция | Два пространства не видят записи и диалоги друг друга |
| LLM-контракт | Валидный JSON, невозможная дата, ошибка провайдера, неизвестная операция, выдуманный ID |
| HTTP | Импорт, список, чат, история, экспорт, cookie, CSRF Origin, невалидные даты, большое тело |
| Сборка | Портативный ESM, export default.fetch, HTML/CSS/JS и health |

Проверки LLM используют подставной ответ провайдера и подтверждают интеграционный контракт, а не качество конкретной реальной модели. Оценка качества свободной речи и нейросетевых парафразов потребует выбранной модели и отдельного размеченного набора.

## Ручной прогон

1. Открыть localhost в Chrome/Edge. Дождаться импорта, перейти во всю историю, проверить 1 000 записей и даты 2024–2027.
2. Создать встречу без времени; перезагрузить страницу; дать время. Убедиться, что запись одна.
3. Выполнить четыре основных сценария из README, в том числе поиск по архиву.
4. Создать пересекающуюся встречу: проверить подтверждение и отмену.
5. Ввести запрос через микрофон, включить озвучку, проверить отказ доступа к микрофону.
6. Создать напоминание на ближайшую минуту; оставить вкладку открытой; проверить уведомление.
7. Проверить ширины 1440, 768 и 390 px, клавиатурную навигацию и фокус.

Браузерный automation surface в окружении реализации недоступен. Поэтому визуальный прогон, реальный микрофон/динамики и разрешения уведомлений не проверены автоматически. Docker-файлы и CI подготовлены; Docker build и удалённый GitHub Actions здесь не запускались. Факт облачной публикации подтверждается результатом сервиса развёртывания; API дополнительно покрыт локальными интеграционными проверками.
